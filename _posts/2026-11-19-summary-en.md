### [Mastra Factory: Open-Source Tool for Software Project Management](https://news.ycombinator.com/item?id=50548660) ⭐️ 7.0/10

Mastra Factory is an open-source software management tool designed to streamline project workflows, particularly for the Mastra framework, which has seen significant growth with nearly 4 million downloads per week. It features a configurable kanban board integrated with Slack, utilizes durable agents for long-running tasks, and supports a markdown-based wiki for documentation. The tool is fully open-source and can be run on personal infrastructure, with a hosted version also available.

**「Background on Mastra Factory」** Mastra Factory is built on the Mastra framework, which is an open-source TypeScript agent framework that has gained significant traction, averaging nearly 4 million downloads per week. The Factory tool is designed to enhance project management and automation within software development workflows, particularly for teams using Slack for communication.
